# Version 0.1.0

Local daily briefings from AI assistant outputs and deadlines with an offline dashboard, CLI and MCP.

Local verification: 21 tests passed; 90% measured coverage; Ruff lint and formatting checks passed. README quick start was exercised with fictional data.

## Known limitations

The index reflects current file modification times rather than immutable historical output versions; reports summarize current task state. PDF preview uses first-page text only, CSV previews show 50 rows, and external task-board entries are read-only. The interface is intended for trusted local use. Optional historical snapshots and watch mode are roadmap features.

See README and AGENTS.md for installation, configuration, machine-readable CLI/MCP interfaces and operational boundaries.
